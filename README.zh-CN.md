# 码灵（Codekin）

[English](README.md)

码灵是一款面向 DeepSeek Harness Web 的精灵收集与三消对战插件。它会将 DSH
运行过程中的高层结果转化为本地游戏事件，不修改提示词、工具、模型请求或 Agent 行为。

![码灵首批 25 只精灵](assets/creatures/sprite-gallery-v1.png)

## 当前内容

- 智算、编译、网络、防护、异常五类计算属性，以及首批 25 只精灵。
- 通过正常使用 DSH 获得的五种品质捕获核心。
- 由运行事件触发的遭遇；失败或恢复类事件可能对应较少见的精灵。
- 地图同时保留最多 7 只野生码灵；低品质目标驻留更久，高品质高等级目标会在较短窗口内离场。
- 混合属性对话仍只刷新一只码灵，但会优先补充候选属性中地图数量较少的一方；单一属性区域超过 5 只后，后续同类对话会向其他稀疏区域分流。
- 普通品质的野生等级根据整个背包分布生成，并保持在背包最低与最高等级之间；星辉与源初会作为高于背包上限的特殊挑战出现。
- 2D 区域地图、7×7 三消战斗、捕获、三只精灵编队和图鉴。
- 五类属性色块构成闭环克制关系，分别产生克制、普通或受抵抗伤害。
- 1–100 级养成、五种品质升级素材、挂机补给与本地进度存档。
- 养成区通过目标选择器一次只展示一只码灵，即使背包扩大也不会不断拉长页面。
- 可在 DSH“设置 → 码灵”中随时启停；停用时保留存档并暂停事件奖励与挂机计时。
- 编队中的码灵可经二次确认放生，并按自身品质返还一份升级素材；返还量不受等级影响。
- 每只出战码灵拥有三个基础行动；四连返还行动、五连增加行动，消除同属性色块可为队员积累指令值。
- 野生遭遇允许提前结束当前码灵的剩余行动，便于保留低运行值目标并进入捕捉窗口。
- 三名队员的伤害按阶段累计，并在队伍轮次结束时以一次总攻结算；每只精灵各有一个被动与一个主动技能。
- 野生码灵采用独立 Boss 数值，并会根据等级和品质使用单体攻击、全体攻击、锁珠、冻结与阶段防护层。
- 四连、五连与交叉消除会生成横排、竖排、爆破和源初特殊色块。
- 由 Host 校验的游戏操作与原子化本地存档。

## 使用方式

正常使用 DSH 即可。完成活动后可能获得捕获核心并触发遭遇。打开码灵入口后，可以探索地图、
调整编队并进入指令三消战。交换相邻色块来累积队伍算力，同时为相同属性的队员积累指令值；三名队员完成行动后，
队伍会统一结算总攻。击败野生码灵可获得升级素材；在总攻后形成捕捉窗口时，也可以根据目标剩余运行值和
捕获核心品质尝试收容。遭遇等级与品质会参考当前会话的有效活动时长。码灵不会提交
提示词、调用工具或修改会话。

## 数据说明

游戏进度由插件保存在本地。码灵只记录有界的游戏事件与聚合后的运行结果，不保存提示词正文、
助手回复、工具参数、命令、工作区路径或原始错误内容。

## 兼容性与状态

仓库当前为适配 DeepSeek Harness Web `0.1.0-rc.5` 的 `0.2.0-rc.4` 体验版本。
在玩法和平衡性评估完成前，软件包保持私有状态。
