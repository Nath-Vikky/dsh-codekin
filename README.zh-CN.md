# 迹境荒野（TraceWild）

[English](README.md)

迹境荒野是一款面向 DeepSeek Harness Web 的像素精灵收集与对战插件。它会将 DSH
运行过程中的高层结果转化为本地游戏事件，不修改提示词、工具、模型请求或 Agent 行为。

![迹境荒野首批 25 只精灵](assets/creatures/sprite-gallery-v1.png)

## 当前内容

- 五类生态区域和首批 25 只精灵。
- 通过正常使用 DSH 获得的五种品质捕获核心。
- 由运行事件触发的遭遇；失败或恢复类事件可能对应较少见的精灵。
- 2D 区域地图、7×7 三消战斗、捕获、三只精灵编队和图鉴。
- 五类色块构成闭环克制关系，分别产生克制、普通或受抵抗伤害。
- 每只出战精灵连续交换三次；消除同生态色块可为队员充能，每只精灵各有一个被动与一个主动技能。
- 四连、五连与交叉消除会生成横排、竖排、爆破和源初特殊色块。
- 由 Host 校验的游戏操作与原子化本地存档。

## 使用方式

正常使用 DSH 即可。完成活动后可能获得捕获核心并触发遭遇。打开迹境荒野入口后，可以探索地图、
调整编队并进入三消遭遇。交换相邻色块来攻击，同时为相同生态的队员充能；一只精灵完成三次交换后，
下一位可行动队员接替。击破护甲并削弱野生精灵后，再选择要消耗的捕获核心品质。迹境荒野不会提交
提示词、调用工具或修改会话。

## 数据说明

游戏进度由插件保存在本地。迹境荒野只记录有界的游戏事件与聚合后的运行结果，不保存提示词正文、
助手回复、工具参数、命令、工作区路径或原始错误内容。

## 兼容性与状态

仓库当前为适配 DeepSeek Harness Web `0.1.0-rc.5` 的 `0.2.0-alpha.1` 体验版本。
在玩法和平衡性评估完成前，软件包保持私有状态。
