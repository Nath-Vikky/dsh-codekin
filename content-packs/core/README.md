# Codekin Core Content

The core content pack describes the 25 Codekin, five ecologies, five qualities, starter choices, Endless Stack rotation, localized creature and skill text, declarative mechanics, and reviewed image assets shipped with Codekin 0.3.7-rc.1. Its appearance assets include 25 level-30 evolutions and five level-60 ultimate portraits with transparent themed scenes and character silhouette masks.

It is validated through Codekin Content API version 1 and is bundled into the installable DSH plugin.
