# Codekin Content SDK

`@nath-vikky/codekin-content-sdk` defines, validates, and combines versioned Codekin content packs. Content packs contain bounded data and references; they do not receive filesystem, network, DeepSeek Harness, or arbitrary code-execution capabilities.

The workspace package is private while content API version 1 is being stabilized. The installable plugin exposes the reviewed build through `@nath-vikky/dsh-codekin/content`.
