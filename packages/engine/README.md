# Codekin Engine

`@nath-vikky/codekin-engine` contains Codekin's deterministic, headless game rules. It has no React, Node.js, or DeepSeek Harness runtime dependency.

The workspace package is private while its content-loading API is being stabilized. The installable `@nath-vikky/dsh-codekin` package exposes the reviewed engine build through its `./engine` export.
